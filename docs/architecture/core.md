# Базовые типы (`core`)

Модули: `core/point.py`, `core/variable.py`, `core/utils.py`.
Здесь нет ни сетки, ни решателей — только примитивы, на которых держится всё
остальное.

---

## `Point` — точка произвольной размерности

**Файл:** `core/point.py`.

### Назначение

Хранит **произвольный** набор координат и служит единым аргументом функций
вместо списка отдельных чисел. Размерность не фиксирована: точка может
описывать `(s, t)`, тройку координат и т. п. Привязки к конкретным именам
координат (`s`, `t`) у точки **нет** — это принципиально (библиотека, а не
решатель под одну геометрию).

### Публичный интерфейс

```python
Point(0, 1)                     # из отдельных чисел
Point([0, 1])                   # из последовательности
Point(1, 2) | Point(3, 4)       # конкатенация → Point(1, 2, 3, 4)

p = Point(0.0, 0.5)
p[0], p[1]                      # доступ к координате по ИНДЕКСУ
len(p)                          # число координат
tuple(p)                        # итерация по координатам
p.coords                        # кортеж координат
p.dim                           # == len(p)
p.asarray()                     # np.ndarray(dtype=float)
p.as_tuple()                    # кортеж
```

- `__eq__` / `__hash__` — по кортежу координат, поэтому `Point` можно
  использовать как ключ словаря (так и хранит данные `NumericVariable`).
- Оператора `|` склеивает координаты двух точек.
- Свойств `s`/`t` **нет и не должно быть** (см. `замечания.md`): порядок
  координат задаёт пользователь, а кто хочет — передаёт в своём порядке.

### Связи

`Point` — ключ хранилища `NumericVariable` и аргумент всех функций
(`AnalyticVariable.at`, `DeferredVariable.at`, `Node`). Ничего не знает о
`System`/сетке.

## `Variable` и его три вида

**Файл:** `core/variable.py`.

### Базовый абстрактный класс `Variable`

```python
class Variable(ABC):
    name: str
    dim: int
    def at(self, point: Point): ...   # абстрактный
```

`dim` — **число компонент** величины на точке: для 2×2 системы `dim=2`
(вектор `[x, y]`), для скаляра `dim=1`. Регистрируется в `System` через
`var_analytic` / `var_numeric` / `var_deferred`.

### 1. `AnalyticVariable` — значение по формуле

```python
AnalyticVariable('B11', lambda point: -2 * point[0], dim=1)
AnalyticVariable('C1', 1)          # константа вместо функции тоже допустима
```

- Хранит функцию `fn(point)` (или константу, завёрнутую в функцию).
- `at(point)` просто вызывает `fn(point)` — данные **не хранятся**,
  значение считается при каждом запросе.
- Обычно `dim=1` → возвращает `float`; `dim=2` → `np.ndarray(2,)`.

**Применение:** коэффициенты (`B`, `F`, `G`, `C`), геометрия области
(`S0/S1/T0/T1`), начальные данные (`x0`, `y0`).

### 2. `NumericVariable` — значения в узлах

```python
v = NumericVariable('X', dim=2)
v.store(Point(s, t), np.array([x, y]))
v.at(Point(s, t))      # → np.ndarray(2,)  или None, если не посчитано
v.storage              # внутренний Dict[(...coords...), np.ndarray]
```

- Хранит значения в словаре `Dict[Tuple[float, ...], np.ndarray]`;
  ключ — **нормированные** координаты точки (`utils.normalize_float`).
- `store(point, value)` — запись (скаляр разворачивается в вектор `dim`).
- `at(point)` — чтение или `None`.
- `_key(point)` — статический метод, строит нормированный ключ.

**Применение:** состояние `X`, сопряжённое `PSI`, граничный прокси `p`.
Именно это хранилище — «интерфейс» между блоками.

### 3. `DeferredVariable` — отложенное (ссылочное) значение

```python
v = DeferredVariable('Z', source_name='Z_num', dim=1)
v.bind(system)                 # привязка к системе (делает var_deferred)
v.at(point)                    # читает значение из source_name
```

- Объявляется **по имени и размерности, без формулы**.
- Хранит `source_name` — имя `NumericVariable`, заполняемой блоком-производителем.
- `at(point)` делегирует чтение в источник; если источник не найден или
  значение ещё не посчитано — **бросает `RuntimeError`**
  (с подсказкой проверить зависимости блоков).

**Связь с другими:** это **однонаправленное ребро графа** «источник →
потребитель». Потребитель (например `DeferredBoundaryBlock`) получает
значение лениво, на том слое, где источник уже посчитан. Это DAG; **циклы
не поддерживаются** (см. [ограничения](../architecture.md#known-limitations)).

### Вспомогательные предикаты

```python
is_analytic(v), is_numeric(v), is_deferred(v)
```

## Утилиты (`core/utils.py`)

```python
PRECISION = 10

normalize_float(x)
```

- `normalize_float` округляет `float`/список/`np.ndarray` до `PRECISION`
  знаков. Убирает погрешность при сравнении координат узлов, чтобы
  «одинаковые» точки давали один ключ хранилища.
- `tuple(normalize_float([s, t]))` — готовый ключ словаря.
- `PRECISION` также используется в `viz/plotter.py` для округления уровней
  координат при построении разрезов.
